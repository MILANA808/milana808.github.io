Проблема

Сотрудники уже используют ИИ. Ответы попадают в письма, справки и решения. Регулятор и суд спросят: на чём основано. Без следа — вы платите за чужую уверенность модели.

Продукт

AKSI DIP — Decision Integrity Platform. Каждый ответ получает машиночитаемую квитанцию: evidence, класс утверждения, gate ALLOW или BLOCK, hash-цепочку для журнала.

Живое демо продукта

Нажмите BLOCK — так система останавливает «уверенный» ответ без источников.

—
FACT HYPOTHESIS CLAIM UNGROUNDED → BLOCK export JSON / audit

Что входит в поставку

1. Decision Receipt Engine

Классификация утверждений, policy strict/companion/lab, gate, proof-hash, экспорт JSON и audit-текста.

2. Встраивание

Обёртка над вашим агентом / API чата: ответ + квитанция. Без замены вашей LLM.

3. Журнал для аудита

Архив решений, фильтр UNGROUNDED, выгрузка под внутреннюю проверку.

4. Closed-loop опция

Работа в контуре без обязательной отправки промптов во внешнее облако (по сценарию внедрения).
