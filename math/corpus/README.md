# AKSI MATH — factual corpus

## Источник знаний
Этот слой содержит только фактические утверждения, вручную отобранные из русской Википедии. Каждая запись хранит URL источника.

Это **не полный дамп Википедии**. Полный корпус Википедии слишком велик для безопасного и практичного встраивания в GitHub Pages. Поэтому runtime должен уметь загружать корпус порциями и хранить происхождение каждого факта.

## Что добавлено
- provenance/source URL для каждого факта;
- отделение фактов от математического механизма;
- возможность расширять корпус без изменения алгоритма.

## Grok/xAI-паттерн
По официальной документации xAI Grok поддерживает серверные Web Search/X Search, code execution и function calling. AKSI не копирует модель или её обучающие данные. Мы заимствуем архитектурный принцип: **получить внешнее свидетельство → сохранить источник → математически оценить → ответить с происхождением**.

Источники: https://docs.x.ai/developers/tools/web-search и https://docs.x.ai/developers/tools/overview
