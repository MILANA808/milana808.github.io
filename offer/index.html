АКСИ — готовый технологический актив

Не обещание «сверхИИ». Набор работающих модулей, открытый код, проверяемые доказательства и упаковка под пилот / лицензию / поглощение команды+кода.

Зачем покупают / берут в пилот

  • Скорость — демо уже в браузере, без месячной «от рисования слайдов».
  • Суверенный контур — offline-first, опциональный свой backend, без обязательного иностранного API.
  • Проверяемость — Pulse, Proof, подписанные мутации Studio, DID агента.
  • Расширяемость — Studio пишет страницы; Kernel — управляемые улучшения; порты LLM под вендоров.
  • Чистота IP — Apache 2.0, NOTICE, без личных данных в публичном дереве.

Три коммерческих формата

1. Пилот 4–8 недель

Внедрение контура у заказчика: Studio + агент + журнал подписей + интеграция одной LLM (Ollama / российский API). Результат — рабочий контур внутри периметра.

2. Лицензия на код + сопровождение

Apache 2.0 уже разрешает использование. Ценность сделки — не «право открыть файл», а передача экспертизы, доработка под ТЗ, SLA, закрытые модули (ЕСИА, ГОСТ-крипто, вендорные драйверы) по отдельному договору.

3. Поглощение / эксклюзив

Репозитории, бренд АКСИ, дорожная карта sovereign, приоритетная команда на 6–12 мес. Оценка — через due diligence кода и пилот, не через лозунги.

Почему может быть дорого

  • Экономия 6–18 месяцев R&D на «суверенный агент + UI + audit».
  • Готовая демонстрация для совета директоров / НТИ / акселератора за 15 минут.
  • Архитектура портов (LLM/crypto) под замену вендора без переписывания ядра.
  • Публичный proof-trail снижает риск «купили дым».

Цена = пилот + дефицит времени рынка, не «магический AGI».

Конкретная цифра — после ТЗ и периметра. Публично фиксируем ценность пакета, не выдуманный чек.

Due diligence за 30 минут

  • 1–3 мин: Pulse — всё ли живо
  • 5 мин: Lab — подпись, агенты, 2-qubit
  • 5 мин: Studio — «создай страницу…»
  • 5 мин: Proof — что confirmed / refuted
  • 5 мин: LICENSE + IDENTITY + sovereign
