Добро пожаловать

АКСИ отвечает на вопросы, помнит заметки и может прочитать текст с фото. Данные остаются в этом браузере.

  1. Напишите вопрос внизу и нажмите ↑
  2. Или нажмите 📷 — чтобы разобрать фото
  3. В «Настройки» можно подключить умную модель (Ollama)

Ответы локально. Для «умных» ответов — Ollama в Настройках.

Разобрать фото

Выберите снимок (PNG, JPG). АКСИ прочитает текст. С моделью llava — опишет картинку.

Результат появится здесь

Память · 0

Заметки хранятся только в этом браузере.

Умная модель (LLM)

Без модели — встроенные ответы. С Ollama — почти как ИИ на вашем ПК.

1. Ollama
2. ollama pull llama3.2
3. Для фото: ollama pull llava

Что умеет АКСИ

Чат — вопросы. «запомни: …» сохраняет факт.

Фото — текст с картинки. С llava — описание сцены.

Память — ваши заметки в браузере.

Настройки — Ollama или API-ключ (ключ не уходит на серверы АКСИ).

Приватность

По умолчанию offline. Сообщения не отправляются на наши серверы.
