Критическое правило контура

Ответ без квитанции не существует как корпоративный артефакт: его нельзя вложить в отчёт, письмо, тикет или API. UNGROUNDED → BLOCK → выпуск запрещён.

Без допуска нет решения

Не «проверьте источники». Жёсткий gate: нет опоры — нет выхода из системы.

ответ ИИ→квитанция→ALLOW→выпуск  |  без опоры→BLOCK→выпуск закрыт

Контур выпуска

ВЫПУСК ЗАПРЕЩЁН. В strict BLOCK нельзя обойти кнопкой «всё равно отправить».
ДОПУСК РАЗРЕШЁН. Квитанция + ответ = корпоративный артефакт.

Зачем критично: когда обход gate = нарушение политики (как файл без грифа). Правило: нет ALLOW → нет легального выхода.
