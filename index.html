Что это честно

АКСИ — помощник в браузере. Не AGI, не «сознание», не облачный сервис по умолчанию. Отвечает сразу offline, данные остаются на устройстве.

Основные функции

  • Чат — локальная база + эвристики + память; при сети — Википедия
  • Ход мысли — короткие шаги рассуждения видны под ответом
  • Подпись — локальный SHA-256 (или Web Crypto) на ответ
  • Заметки и файлы — IndexedDB / localStorage
  • Квант-демо — учебный Bell / суперпозиция на 2 кубитах
  • Счёт и голос — калькулятор и Web Speech API
  • LLM — опционально, локальный backend + Ollama

Эффективность продукта

9/10старт без установки 8/10приватность по умолчанию 7/10понятность интерфейса 5/10глубина ответов без LLM 8/10прозрачность логики

Прогноз

Сильная сторона — local-first и понятный UX. Слабая — качество ответов без своей LLM. Рост: подключить локальную модель (Ollama), расширить базу фактов, держать интерфейс простым. Не обещать AGI — обещать полезный offline-чат.
