Локальная LLM

Необязательно. Ollama + backend на вашем компьютере.

  1. Установите Ollama, затем: ollama pull qwen2.5:3b && ollama serve
  2. В папке backend: ./start.sh
  3. URL: http://127.0.0.1:8000

Подробнее: BACKEND.md · расширенный чат: /chat/

О продукте

АКСИ — помощник в браузере. Отвечает offline. Данные по умолчанию не уходят с устройства. Облако и LLM — только если вы сами включите.

Что умеет

  • Чат: база знаний, эвристики, память, Википедия
  • Ход мысли и локальная подпись ответа
  • Заметки и файлы (IndexedDB / localStorage)
  • Учебный квант-демо (2 кубита)
  • Счёт, голос, локальный ID
  • Опционально: локальная LLM (Ollama)
