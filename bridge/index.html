AKSI is designed as a neutral layer around existing AI systems. It does not require replacing the model. It records provenance, integrity, uncertainty and execution outcome in a portable evidence envelope.

Three-line integration

<script src="/bridge/aksi-bridge.js"></script>
const result = await AKSIBridge.wrap(request, runModel, {
  model: "your-model", intent, context, source_refs
});

What the bridge does

  1. Preserves the original model/runtime.
  2. Hashes intent, context and result.
  3. Attaches sources, actions, experiments and uncertainty.
  4. Returns a portable AKSI-VAI/1 evidence record.
  5. Leaves authorization and external execution to an explicit policy/action gateway.
