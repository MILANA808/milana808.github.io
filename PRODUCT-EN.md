# AKSI — Product (Release 1.0)

## One line
**Local-first AI in the browser:** ask → answer on-device → teach facts → encrypt memory. Cloud is optional.

## Who it’s for
- People who care about **privacy**
- Users who need **offline** intelligence without an account
- Teams building a **sovereign agent runtime**, not another SaaS chatbot

## Product model (4 actions)

| Action | Tab | What happens |
|--------|-----|--------------|
| **Ask** | Chat | Offline core (Mind L2 + Neuro) |
| **Teach** | Memory | Fact → local RAG |
| **Protect** | Trust | AES + `.aksi` file |
| **Verify** | Lab | Answer score (QCLI) + client-side simulation |

Optional: large LLM (WebGPU), manual P2P SDP.

## Honest tech note
The Lab “quantum” layer is a **client-side simulator and integrity metric**. It is **not** access to a physical quantum computer.
