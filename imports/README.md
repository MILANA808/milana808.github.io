# imports/

Сюда складывай проекты, перенесённые из **Replit** (и других песочниц).

1. Открой https://milana808.github.io/import/
2. Скачай ZIP из Replit или вставь файлы
3. Положи код в `imports/<имя-проекта>/`
4. `git add` · `commit` · `push`

Секреты (API keys) **не** коммить — только `.env.example`.
