# AKSI Net v2.0 — полноценная нейросеть

## Архитектура

**Embedding + MLP next-char**

1. Символ → вектор embedding (E=24)
2. Контекст CTX=8 символов → конкат
3. Скрытый слой H=64, **ReLU**
4. Softmax по словарю → следующий символ
5. **Обучение:** SGD + полный backprop (включая embeddings)

## Обучение

Предобучена на seed-корпусе АКСИ: **loss ≈ 0.08**, 90k шагов.
Веса: `/aksi-net-weights.json`

```js
AKSI_NET.loadPretrained() // или train() / generate()
```
