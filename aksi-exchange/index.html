AKSI Exchange

Обмен AKSI на настоящий BTC в сети Bitcoin и обратно. Котировки агрегируются через 0x Cross-Chain API. Подписание всегда происходит в твоём собственном кошельке.

1. Подключение сервиса

Worker не подключён. После публикации Worker укажи его HTTPS-адрес.

Адрес сервиса хранится только в localStorage этого браузера. API-ключ 0x сюда не вводить.

2. Направление и сумма

AKSI · 18 знаков после запятой

AKSI → BTC: отправитель — Base-кошелёк, получатель — Bitcoin-адрес. BTC → AKSI: отправитель — Bitcoin-кошелёк, получатель — адрес Base. Для автоматической подписи BTC сейчас поддерживается UniSat Wallet.

Сначала подключи Worker и проверь соединение.

Кнопка исполнения включается только после получения котировки с доступной ликвидностью. Последняя котировка будет обновлена перед подписью.

3. Статус операции

Операций пока нет.

Безопасность и ограничения

Сайт не получает seed-фразы и приватные ключи. EVM-транзакции подписываются в EVM-кошельке, Bitcoin PSBT — в UniSat. Перед подтверждением внимательно проверь сумму, адрес получателя и комиссию в своём кошельке. Не подтверждай неизвестные транзакции.

Для реального обмена нужны развёрнутый ERC-20 AKSI в Base, настроенный Worker с секретом 0x и ликвидность AKSI. Если API не находит маршрут, обмен невозможен — сайт не создаёт фиктивную цену. WBTC не используется: целевой актив — native BTC.

BTC → AKSI: Bitcoin-транзакция после подписи публикуется через UniSat; затем статус кросс-чейн операции отслеживается у 0x. AKSI → BTC: EVM-кошелёк может запросить allowance и отправить транзакцию в Base.
