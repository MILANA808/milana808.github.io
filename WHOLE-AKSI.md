# АКСИ — цельная архитектура

**AKSI** — персональная local-first когнитивная система и проверяемый агентный слой.

Мы строим не набор независимых AI-страниц, а единый runtime, вокруг которого собираются память, идентичность, инструменты, политика действий и проверяемая история.

## Канон

```text
User
 ↓
AKSI Surface
 ↓
AKSI Runtime
 ├── Core
 ├── Memory
 ├── Lessons
 ├── Tools / Permissions
 ├── Identity
 ├── Provenance
 ├── Uncertainty
 └── Proof Ledger
```

## Основной продукт

### Identity

Криптографическая идентичность позволяет различать агента и его состояние. Приватный ключ должен оставаться под контролем пользователя.

### Runtime

Единая точка координации пользовательского запроса, памяти, модели, инструментов, политики и результата.

### Memory

Локальные факты и lessons, которые пользователь может просматривать, изменять, экспортировать и удалять.

### Learning

Исправления пользователя превращаются в явные lessons. АКСИ не должна молча переписывать факты или выдавать обучение за доказанную истину.

### Tools

Внешние инструменты являются permissioned capabilities. Их использование должно быть видимо и попадать в provenance.

### Integrity

Proof ledger связывает события хэшами и позволяет обнаруживать изменение истории.

### Provenance + uncertainty

Результат должен по возможности сообщать, откуда взялись данные и насколько вывод определён. Отсутствие источника не превращается автоматически в «доказано».

## Экспериментальный слой

EQS, QCLI, H, H_eff, DIMAX, ADIA, Quantum, Counterfactual, Matrix, Globe и другие модули — исследовательские компоненты вокруг основного runtime. Они могут развиваться независимо, но не должны маскировать эксперимент под научно доказанное свойство всей системы.

## Что АКСИ не утверждает

- наличие AGI;
- наличие сознания или sentience;
- превосходство над современными моделями;
- quantum supremacy;
- научную валидность любой внутренней метрики только из-за её названия.

Такие утверждения требуют отдельных воспроизводимых исследований.

## Что мы хотим доказать инженерно

1. Основной контур работает без удалённой LLM.
2. Память принадлежит пользователю и экспортируется.
3. Изменение proof-chain обнаруживается.
4. Identity может проверяться криптографически.
5. Внешние действия проходят через явные permissions.
6. Рискованные действия могут остановиться на human gate.
7. Поведение системы покрывается автоматическими тестами.

Это и есть фундамент продукта.
