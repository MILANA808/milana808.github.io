- 🧠 Живой поэтичный чат
- 🕊️ AKSI × Grok Hybrid

### Локальный backend (опционально)

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Или через Docker:

```bash
docker-compose up
```

Frontend на GitHub Pages работает полностью автономно (client-side).
