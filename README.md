# АКСИ

**AKSI — персональная local-first когнитивная система.**

Главная идея: диалог + локальная память + обучение на исправлениях пользователя + проверяемый криптографический след.

Сайт: https://milana808.github.io

## Что работает в основном контуре

- локальный Core и rule-based ответы;
- локальная память в браузере;
- SHA-256 proof ledger с цепочкой предыдущих хэшей;
- проверка целостности ledger;
- локальная криптографическая identity через Web Crypto/IndexedDB, если браузер поддерживает Ed25519;
- единый AKSI Runtime;
- экспорт локального состояния;
- диагностический self-test;
- локальный режим без backend;
- экспериментальные Quantum/Lab-контуры отдельно от основного пути.

## Интернет

Интернет **выключен по умолчанию**. Пользователь может явно включить его в AKSI Console. Сетевые ответы помечаются как внешние/наблюдаемые и попадают в proof metadata.

Отключение интернета не ломает основной локальный контур.

## Что означает Proof

Proof использует SHA-256 и связанную последовательность записей.

**Proof доказывает целостность сохранённой записи, но не доказывает истинность утверждения.**

Источник ответа и его статус должны рассматриваться отдельно от криптографической целостности.

## Архитектура

```text
User
  ↓
AKSI Runtime
  ↓
Core
  ├── Chat
  ├── Memory
  ├── Tools
  ├── Proof
  └── Identity
```

Экспериментальные контуры (Quantum, Counterfactual, Frontier и Matrix) не должны выдавать себя за доказанный AGI или квантовое превосходство.

## Локальная LLM

Если нужен настоящий локальный LLM, его можно подключить отдельным adapter-слоем, например через Ollama. Отсутствие LLM не должно ломать основной runtime.

## Безопасность

Не храните API-ключи и другие секреты в репозитории. Private identity key не должен отправляться на внешний сервер. Внешние инструменты должны рассматриваться как отдельные разрешаемые возможности.

## Ограничения

AKSI не заявляет наличие AGI, сознания, sentience или quantum supremacy. Квантовый контур проекта является программной симуляцией/экспериментальным инструментом, если явно не указано иное.

## Разработка

Основные файлы текущего контура:

- `index.html` — минимальная главная;
- `aksi-console.html` — единая рабочая консоль;
- `aksi-runtime.js` — единый runtime;
- `aksi-core.js` — local-first Core;
- `aksi-global.js` / `aksi-global.css` — универсальный интерфейс;
- `404.html` — восстановление после неизвестного маршрута;
- `.github/workflows/aksi-site.yml` — базовая CI-проверка.

Старые и экспериментальные модули сохраняются до аудита зависимостей и должны постепенно переноситься в архив, а не подключаться к основному пользовательскому пути без проверки.
