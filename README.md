# АКСИ

Локальный помощник в браузере.

**Сайт:** https://milana808.github.io  
**Контакт:** aksilove@internet.ru

## За 10 секунд

Откройте сайт → пишите в чат внизу. Работает без установки и без сервера.

## Функции

- Чат offline + ход мысли + локальная подпись
- Заметки и файлы на устройстве
- Поиск (Википедия), счёт, голос
- Учебный квант-демо (2 кубита)
- Опционально: локальная LLM (`backend/` + Ollama)

## Не это

Не AGI. Не облачный ИИ по умолчанию. Данные остаются у вас.

## LLM (по желанию)

```bash
ollama pull qwen2.5:3b && ollama serve
cd backend && ./start.sh
```

В `/chat/` укажите `http://127.0.0.1:8000`.
