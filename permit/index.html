AKSI Action Permit

Агент не выполняет опасный tool-call без мандата. Каждый ALLOW/BLOCK — подписанная квитанция (ECDSA) для audit.

Зачем: LLM-агенты уже вызывают HTTP, файлы, платежи. Без gate инцидент — вопрос времени. Permit — слой между «модель решила» и «система сделала».

goal → mandate → intent → ALLOW | BLOCK → signed receipt → offline verify
