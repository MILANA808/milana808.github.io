# АКСИ — Суверенный экзокортекс (каркас v0.1)

Реализация **первого слоя** ТЗ на клиенте (без обязательного сервера).

## Сделано сейчас

| Компонент | Путь | Статус |
|-----------|------|--------|
| Context Bus (intent + SHA-256) | `/kernel/aksi-bus.js` | работает |
| Микроядро модулей | `/kernel/aksi-kernel.js` | работает |
| Persona АКСИ / Милана / вместе | `/kernel/modules/persona.js` | работает |
| Cognitive UI (эвристики) | `/kernel/modules/cognitive.js` | работает |
| Реестр навыков + подпись | `/kernel/modules/skills.js` | работает |
| UI экзокортекса | `/exocortex/` | работает |
| Net-first чат-ядро | `/aksi-core.js` | работает |

## В ТЗ, но не в v0.1 (честно)

- ONNX Runtime Web + локальная LLM — нужен вес модели и отдельная сборка
- Федеративное обучение — нужен согласованный протокол и узел агрегации
- WebRTC mesh + TURN — нужен сигнальный сервер
- Полная Shadow DOM модульная витрина — следующий итерационный слой

## Принципы, уже соблюдённые

1. Данные по умолчанию **локально** (localStorage)
2. Модули общаются через **Bus**, не напрямую
3. Intent несёт **подпись**
4. Два режима агента + unified
5. UI может **разряжаться** при «перегрузке» (частота сообщений)
