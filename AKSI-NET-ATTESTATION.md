## 1. Честная формулировка (важно)

AKSI **не** объявляет новую фундаментальную «породу» нейросети в смысле замены Transformer/CNN в академической классификации.

AKSI фиксирует **конкретную обученную систему** и **конвейер решения**:

1. **Personal Net** — классический MLP-классификатор по признакам текста  
2. **Mind** — оркестрация: личная сеть → интернет (Wikipedia) → опциональная LLM с таймаутом  
3. **Правило «не молчать»** — всегда есть ответ или явный отказ с подсказкой

Новизна для продукта — в **сборке, политике ответа и привязке к локальной памяти**, а не в изобретении нового уравнения активации «с нуля».

## 2. Математика Personal Net

### 2.1. Признаки (feature map)

Текст приводится к нижнему регистру. Строятся **символьные триграммы**.  
Каждая триграмма хешируется в индекс j ∈ {0,…,F−1}, F = 256.

Вектор признаков x ∈ R^F нормализуется L2-нормой.

### 2.2. Сеть (MLP)

Скрытый слой ReLU (H=48), выход Softmax по K=26 классам-ответам:

- h = ReLU(W₁x + b₁)
- y = W₂h + b₂
- p = softmax(y)

Предсказание: argmax p_k.  
Отказ (low-confidence), если max p < 0.35 или margin < 0.08.

### 2.3. Обучение

Loss = −log p_{k*} (cross-entropy), SGD + decay LR, backprop.

**Прогон 2026-09-17:**

| Метрика | Значение |
|--------|----------|
| Классы | 26 |
| Эпохи | 150 |
| Loss | ≈ 0.29 |
| Accuracy на эталонах | 26/26 |
| Параметров | ≈ 13.5k |

### 2.4. Mind

A = LLM (если ready) → иначе personal⊕web → иначе web → иначе personal → иначе явный отказ.
LLM timeout 55s; при сбое не блокирует ответ.
