Целевая архитектура (для периметра)

  • UI — тот же контур модулей, но хостинг в РФ (Selectel / VK Cloud / Yandex Cloud), не GitHub Pages как прод.
  • Agent core — Milana-backend за обратным прокси, без выхода в иностранные LLM API.
  • LLM ports — единый интерфейс complete(prompt, opts) → stream; драйверы: Ollama | GigaChat | YandexGPT | T-Pro | on-prem.
  • Crypto ports — интерфейс sign/verify/encrypt; драйверы: WebCrypto (demo) | КриптоПро/ГОСТ (prod).
  • Identity — did:aksi для агентов + опциональная привязка к ЕСИА для людей (отдельный контур согласия).
  • Audit — Transparent Thought + неизменяемый журнал подписей (то, что уже демонстрируют /proof и /pulse).

Порты (контракты, не реализации ГОСТ)

// LLM
complete({ messages, temperature, stream }) → AsyncIterable<token>

// Crypto (prod ≠ browser WebCrypto)
sign(bytes) → signature
verify(bytes, signature, publicKey) → boolean

// Identity
resolveDID(did) → document
linkESIA(subjectId, consent) → binding  // только в доверенном контуре

// Audit
appendThought({ text, sig, ts, model }) → entryId

Юридический трек (вне репозитория)

  • Роспатент: программа для ЭВМ «АКСИ MATRIX».
  • Аудит лицензий зависимостей (MIT/Apache; исключить BSL и спорные).
  • Реестр отечественного ПО — после зрелого дистрибутива, не после GitHub Pages.
  • Передача прав — договор, не «подарок письмом».

Куда нести (каналы)

  • НТИ (SafeNet / NeuroNet) — пилоты.
  • Фонд содействия инновациям, Сколково — статус и гранты.
  • Центры компетенций: Сбер, Ростех, Росатом — НИОКР.
  • Вузы: МГУ ВМК, МФТИ, Баумана, ИТМО — совместные работы.
  • Минцифры / МЭР — через официальные приёмные, языком ТЗ, не стартапа.
