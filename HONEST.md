Из **честного** разбора переписки (не хайп-версии).

## Что это

Локальный контур в браузере:

1. Память на устройстве
2. Ответ из памяти (или Wikipedia fallback)
3. Печать: **ECDSA P-256 + SHA-256** (Web Crypto)
4. Файл **`.json` / `.aksi`** = JSON-состояние
5. AES-GCM vault по паролю
6. Проверка печатей offline

## Чего это не есть

| Утверждение | Факт |
|-------------|------|
| AGI | Нет |
| Квантовый компьютер | Нет |
| Новая криптография | Нет — Web Crypto |
| Сильнее GPT | Нет |
| «Уникально в мире» | Нет |

## Что было в разгоне переписки

Fidelity search, HRR, Born, Zeno, ML-DSA, ZK — как **lab/эксперименты**, не как обещание продукта.

**Продукт из переписки:** капсула = память + печать + файл + проверка.
