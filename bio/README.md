# AKSI BioMind

Research module for running computational nervous systems inside an AKSI environment.

## Roadmap

1. C. elegans baseline (small connectome, reproducible end-to-end loop).
2. Drosophila connectome import and neuron/synapse mapping.
3. Spiking dynamics and plasticity.
4. Embodied environment and sensorimotor loop.
5. State snapshots and AKSI-VAI evidence records.
6. Hybrid LLM interface and tool bridge.
7. Comparative benchmark across biological and artificial substrates.

## Scientific boundary

A connectome is anatomical connectivity, not a complete digital copy of an organism. A computational simulation is not evidence of consciousness. Claims about learning or behavior must be tied to measurable experiments and reproducible configurations.

## Data policy

This repository should reference external scientific datasets by stable identifiers and licenses rather than copying restricted datasets into the website repository.
