Идея

AKSI BioMind — не утверждение о цифровом сознании. Это экспериментальная среда: реконструированная нервная система получает тело, сенсорный поток, среду, опыт и механизмы обучения. Каждый эксперимент может сохраняться как проверяемое состояние.

🪰 Drosophila

Подключаем опубликованные connectome-данные и вычислимые модели нервной системы мухи.

🪱 C. elegans

Меньшая система для первого end-to-end эксперимента: мозг → тело → среда → обучение.

🧠 Hybrid Mind

LLM может выступать языковым и инструментальным интерфейсом, не подменяя биологическую модель.

🔐 Evidence

Сохраняем stimulus, neural state, action, outcome, learning delta и хэши состояния через AKSI-VAI.

Экспериментальный цикл

connectome → neural dynamics → body → environment → action → outcome → plasticity → memory → evidence

Что проверяем

  • скорость обучения и адаптации;
  • память и обобщение;
  • устойчивость поведения при изменении среды;
  • разницу между connectome-моделью, SNN, LLM и гибридом;
  • воспроизводимость каждого эксперимента.

Честные границы

Connectome не равен полной копии живого мозга. Модель не равна сознанию. Симуляция не равна биологическому организму. Эти различия являются частью протокола эксперимента.
