# АКСИ Admin UI

Публичная панель: **https://milana808.github.io/admin/**

## Требования
1. Запущенный [Milana-backend](https://github.com/MILANA808/Milana-backend) v0.4+
2. В браузере указать API (по умолчанию `http://localhost:8000`)
3. Токен: `X-Admin-Token` = `AKSI_ADMIN_TOKEN` (dev: `aksi-admin-dev`)

## Возможности UI
- Health / identity / Ed25519 proof
- Admin stats & system
- Список пользователей, block
- Список агентов
- Тест `POST /api/chat`

## Не путать с
Полным React-Admin monorepo из «идеального ТЗ». Это **работающий** стеклянный UI на Pages + реальный API.
