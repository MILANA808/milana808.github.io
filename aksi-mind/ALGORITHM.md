# AKSI MIND — алгоритм разговорного интеллекта

## Что уже реализовано в прототипе
- Приём текста и базовая классификация намерений.
- Генерация ответов по встроенным правилам.
- Извлечение заметок по пересечению слов.
- Явная команда сохранения «Запомни: …».
- Локальная память браузера через localStorage, очистка памяти.
- Интерфейс без внешних библиотек и без API-ключей.

Это детерминированное демонстрационное ядро, а не обученная LLM и не квантовый компьютер. Оно не умеет надёжно отвечать на произвольные вопросы; неизвестные запросы должны явно маршрутизироваться к языковой модели.

## Целевая архитектура
1. **Input adapter**: текст, далее — речь-to-text.
2. **Intent router**: вопрос, команда, воспоминание, поиск, генерация, инструмент.
3. **Context builder**: последние сообщения + релевантная долговременная память.
4. **LLM adapter**: сменный провайдер — локальная модель в браузере/на устройстве либо серверная модель. Секретные ключи нельзя хранить в статическом фронтенде.
5. **Tool runner**: инструменты с проверкой схемы, разрешений и тайм-аутов.
6. **Verifier**: отделяет известные факты от предположений; проверяет формат и ссылки; не выдаёт симуляцию за реальное квантовое вычисление.
7. **Memory gate**: сохраняет только по явному запросу пользователя либо согласно прозрачной настройке.
8. **Output adapters**: потоковый текст, затем синтез речи.
9. **Evaluation**: набор русскоязычных тестов на следование инструкциям, галлюцинации, память, безопасность, задержку и восстановление после ошибки.

## Псевдокод
```text
handle(input, session):
    parsed = normalize_and_classify(input)
    context = session.recent_turns
    memories = retrieve_relevant_memory(parsed, user_consent=true)
    if parsed.kind == "remember":
        return save_local_memory(parsed.payload)
    if parsed.kind == "clear_memory":
        return clear_memory_after_confirmation()
    prompt = build_prompt(parsed, context, memories, safety_rules)
    draft = llm_adapter.generate(prompt, stream=true)
    answer = verify_and_label_uncertainty(draft)
    session.append(input, answer)
    if user_explicitly_requested_memory(input):
        save_memory(input)
    return answer
```

## Критерии готовности настоящего разговорного ядра
- Свободная генерация текста через реальную языковую модель, а не набор шаблонов.
- Проверенные входные и выходные интерфейсы модели.
- Явное управление памятью, экспорт/удаление данных.
- Набор автоматических тестов на реальные диалоги.
- Режим без сети только при наличии загруженной локальной модели; без модели офлайн доступен лишь ограниченный базовый слой.
- Квантовый модуль подключается как отдельный экспериментальный инструмент. Он не заменяет LLM и не доказывает квантовое происхождение интеллекта.
