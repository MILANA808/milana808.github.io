# AKSI MIND — разговорное ядро

## Реализовано
- Русскоязычный чат в `/aksi-mind/`.
- Подключение существующего `/aksi-webllm.js` из главного репозитория.
- Кнопка явного запуска WebLLM, выбор модели, индикатор загрузки и отображение backend.
- Локальная генерация через WebLLM/WebGPU после успешной загрузки модели.
- История текущей беседы передаётся в контекст; релевантные заметки локальной памяти могут добавляться в системный контекст.
- Команды явного сохранения, просмотра и очистки заметок в localStorage.
- Честный базовый режим, когда WebGPU/модель недоступны; он не маскируется под LLM.

## Как проверить
1. Откройте страницу через HTTPS: `/aksi-mind/`.
2. Нажмите «Загрузить ИИ» и дождитесь статуса готовности. Первый запуск скачивает runtime и веса модели.
3. После статуса «локальная модель активна» задайте произвольный вопрос: ответ должен прийти через WebLLM.
4. Если WebGPU не поддерживается, будет показана ошибка и останется ограниченный режим правил.
5. В DevTools Network проверьте, что загружается WebLLM и модель; пользовательский текст не отправляется на облачный LLM этим адаптером.

## Целевая архитектура
1. Input adapters: текст, далее — speech-to-text.
2. Intent router: вопрос, команда, память, поиск, генерация, инструмент.
3. Context builder: недавняя история + релевантная локальная память.
4. LLM adapter: WebLLM/WebGPU сейчас; позже можно добавить llama.cpp localhost или иной backend.
5. Tool runner: инструменты с проверкой схемы, разрешений и ограничений.
6. Verifier: отделяет факты от предположений, проверяет ссылки и формат; не выдаёт симуляцию за реальное квантовое вычисление.
7. Memory gate: явное сохранение, прозрачный экспорт и удаление.
8. Output adapters: потоковый текст, затем синтез речи.
9. Evaluation: русскоязычные тесты на инструкции, фактические ошибки, память, безопасность, задержку и восстановление.

## Ограничения
- Это не новая модель, обученная с нуля: WebLLM запускает существующую открытую модель на устройстве.
- WebGPU зависит от браузера и оборудования; поддержка на iPhone/iOS может отсутствовать.
- Первый запуск требует интернета для загрузки runtime/весов; офлайн-поведение зависит от кэша браузера.
- Маленькие локальные модели слабее крупных облачных моделей; ответы нужно проверять.
- Квантовый симулятор — отдельный вычислительный эксперимент, он не заменяет языковую модель и не доказывает квантовое происхождение интеллекта.
- Не размещайте секретные ключи в статическом frontend.
