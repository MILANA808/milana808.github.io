Что можно: локальные циклы, отчёты на эту страницу, сохранение URL Gateway OpenClaw, который вы сами создали.
Чего нет: «обучить модель на всё знание мира» и «агент сам регистрируется на OpenClaw за вас».

1. OpenClaw — делает человек

  1. Установка: curl -fsSL https://openclaw.ai/install.sh | bash
  2. Онбординг: openclaw onboard --install-daemon
  3. Свой API-ключ модели — только у вас
  4. Проверка: openclaw gateway status (часто порт 18789)
  5. Документация: docs.openclaw.ai

Облачные зеркала (openclaw.ru и т.п.) — регистрация и оплата на их сайте вручную.
