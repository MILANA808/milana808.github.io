## Технологический вклад (честно)

Не «первые знания в истории науки».  

**Вклад АКСИ:** локальный движок, где знание:

1. **Кристаллизуется** в sealed atom (ℂ^D + seal hash)  
2. **Связывается** holographic bind (круговая свёртка)  
3. **Извлекается** correlation / Born + lexical  
4. **Выводится** derive с **provenance**  
5. **Сохраняется** offline

Новое знание = факт с печатью **или** derived statement с цепочкой источников.

## Команды

