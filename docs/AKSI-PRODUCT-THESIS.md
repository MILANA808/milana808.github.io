# AKSI Product Thesis

## Product
AKSI is a verification and control layer for AI agents. It records provenance, permissions, uncertainty, memory changes and cryptographic integrity around an agent result.

## The wedge
Do not compete with foundation models. Integrate with them.

`AI model / agent -> AKSI -> tools, memory, policy, proof -> result`

## Core promise
An organization can inspect a consequential AI result and answer:

1. What was requested?
2. What data and tools were used?
3. Which external permissions were active?
4. What evidence/provenance was attached?
5. What uncertainty was reported?
6. Was the audit record modified after creation?
7. What human approval was required?
8. What changed in memory or policy afterward?

## Product surfaces
- Browser demo: visual, zero-install proof of the concept.
- JS SDK: embed verification into an existing agent.
- Local runtime: local-first storage and cryptographic primitives.
- Audit export: portable JSON proof bundle.
- Policy gate: explicit permissions for external tools.

## Important distinction
A cryptographic hash proves integrity of the recorded bytes, not truth of the underlying claim. A provenance record proves what was recorded as a source, not that the source itself was correct.

## Commercial path
1. Open-source demonstrator.
2. Developer SDK.
3. Team audit dashboard.
4. Enterprise policy, retention and integrations.
5. Security/compliance partnerships.

No valuation is implied by this document. Commercial value must be demonstrated by adoption, reliability, integration and measurable risk reduction.
