# Contributing / Участие

## RU

1. Форкните `MILANA808/milana808.github.io`
2. Ветка `feature/...`
3. Не коммитьте секреты, пароли, токены
4. Перед PR: откройте `/tests/` и убедитесь, что ключевые тесты зелёные
5. UI — бежевая тема, offline-first
6. Публичный контакт только `aksilove@internet.ru`

## EN

1. Fork the repo
2. Feature branch
3. No secrets in commits
4. Run `/tests/` before PR
5. Keep beige offline-first UI
6. Public contact: aksilove@internet.ru only

Thank you / Спасибо.
