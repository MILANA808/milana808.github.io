# Изобретение: Нить АКСИ (Strand Protocol)

## Проблема

Чат = лента сообщений без жёсткой связи «вопрос↔ответ».  
Wiki = страницы без диалога.  
Нужна форма, где **пара мыслей** (человек + агент) становится **одним заверенным объектом**.

## Решение

**Звено нити** = (искра человека, контр-искра АКСИ, prev, ts, DID)  
**Печать пары** = SHA-256(seed | STRAND/1 | DID | ts | prev | you | aksi)

Каждое следующее звено включает `prev` = печать предыдущего → локальная хеш-цепь.

## Чем это не «просто чат»

| | Чат | Нить |
|--|-----|------|
| Единица | сообщение | **пара** |
| Подпись | опционально на текст | **обязательна на пару** |
| Порядок | UI-лента | **хеш-цепь** |
| Смысл | поток | **сплетение** |

## Ограничения (честно)

- Seed на клиенте → это **доказательство целостности на устройстве**, не глобальный блокчейн.
- Контр-искра генерируется правилами + Net + ядро знаний, не большим LLM (без сервера).
