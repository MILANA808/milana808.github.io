# AKSI Native Mind — архитектура и проверяемые гипотезы

## Цель
Создать минимальное когнитивное ядро, которое не вызывает WebLLM, не загружает модельные веса и не использует внешние API. Это не LLM и не доказанный прорыв; это собственная экспериментальная символьная система.

## Реализовано
- Локальная HTML/JavaScript реализация без сторонних библиотек.
- Понятийный граф со взвешенными рёбрами и распространением активации с затуханием на трёх проходах.
- Локальные пользовательские записи через localStorage; записи маркируются как пользовательские, а не как проверенные факты.
- Простейшее разложение цели на наблюдаемые шаги.
- Прозрачная трасса вывода и оценка внутренней опоры, не называемая вероятностью истинности.
- Неизвестные запросы приводят к уточнению вместо свободной выдумки.
- Очистка локальной памяти и индикаторы состояния графа.

## Алгоритм активации
1. Нормализовать запрос (нижний регистр, ё→е, знаки препинания).
2. Точное совпадение токена с терминами узла добавляет 1.5, частичное совпадение — 0.55.
3. Три прохода по направленным ассоциациям распространяют активацию соседям с коэффициентом 0.28 × вес ребра.
4. Отсортировать активированные понятия; использовать их для объяснения или выбора ограниченного правила ответа.
5. Отобразить путь рассуждения и ограничение уверенности.

## Что нужно проверить
- Набор не менее 100 русскоязычных запросов, размеченных вручную по намерению.
- Метрики: accuracy по типу задачи, доля необоснованных ответов, точность извлечения локальных заметок, задержка и объём хранимой памяти.
- Сравнить с простым keyword baseline и с версией без распространения активации.
- Провести абляцию: выключить память, графовые связи и цель-разложение по одному.
- Проверить браузеры и сценарии, где localStorage запрещён/очищен.
- Не заявлять превосходство над LLM без воспроизводимого эксперимента.

## Ограничения
Система не понимает произвольный язык как LLM, не распознаёт речь, не проверяет факты в интернете и не обучает новые общие знания из пользовательского текста. Добавление неизвестных токенов в словарь — это адаптация словаря, а не обучение модели. Оценка внутренней опоры эвристическая. Браузерный localStorage не синхронизируется между устройствами и может быть удалён пользователем.

## Следующий исследовательский шаг
Создать воспроизводимый тестовый корпус, фиксированные expected outputs и отчёт сравнения с keyword baseline. Только измеримый выигрыш на конкретном классе задач позволит говорить о полезном новом методе.
