Browser API

Подключите скрипты Contour/ADIA, затем aksi-api.js. Всё работает в браузере без сервера.

const r = await AKSI.decide("Кто ты?");
// r.answer, r.scores.aksi, r.gate.ok, r.seal

const t = await AKSI.think("формула AKSI");
const s = AKSI.evaluate("q", "текст ответа");
await AKSI.learn("запомни: мой факт");
console.log(AKSI.status());
