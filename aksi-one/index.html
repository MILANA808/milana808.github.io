Архитектура исполнения

1Intent Router
Определяет тип задачи или использует выбранный режим.
2Bounded Executor
Исполняет только разрешённые локальные операции; не использует eval/Function.
3Trace + Memory
Показывает этапы и сохраняет выбранные пользователем записи на устройстве.
4SHA-256 Receipt
Фиксирует вход, режим, результат и журнал в целостной квитанции; это хэш целостности, не цифровая подпись личности.
