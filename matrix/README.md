# АКСИ MATRIX v2

Локальный квантовый симулятор + агент АКСИ на GitHub Pages.

## Возможности
- Statevector: H,X,Y,Z,S,T,CNOT,SWAP,Toffoli
- Оптимизатор пар гейтов (HH→I, CNOT·CNOT→I)
- DSL ↔ схема, OpenQASM 2.0, Qiskit-текст
- Шаблоны: Белл, GHZ, телепортация, Дойч
- Сферы Блоха, арт по амплитудам + hash
- Демо NFT-сертификат (локальный JSON+SHA-256)
- Wikipedia по запросу «найди …»
- Шаринг схемы `?scheme=`

## Честно
Нет минта ERC-721 в mainnet по умолчанию. Генерация алгоритмов — шаблоны + DSL, не обученный трансформер.
