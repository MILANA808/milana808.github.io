# АКСИ — продукт

## Решение по аудиту

Оставлены только функции, которые работают в браузере без обязательного сервера.
Убраны маркетинговые страницы (прецедент, AGI, mesh, NFT и т.п.).

## Работает

| Функция | Оценка | Комментарий |
|---------|--------|-------------|
| Offline-чат | 8/10 | База + эвристики + память |
| Ход мысли + подпись | 8/10 | SHA-256 / Web Crypto локально |
| Заметки / файлы | 8/10 | IndexedDB + localStorage |
| Википедия | 7/10 | Нужен интернет |
| Квант-демо 2q | 7/10 | Учебный, не hardware |
| Счёт / голос | 7/10 | Зависит от браузера |
| LLM backend | 6/10 | Опционально, Ollama |

## Не заявляется

AGI · сознание · обязательный облачный API · юридический DID

## Прогноз

1. Держать offline-first как главное УТП.
2. Расширять локальную KB и память.
3. LLM — только как opt-in (локальный backend).
4. UI — одна страница, без мёртвых модулей.
