# АКСИ — продукт

Одна главная страница. Слева — вкладки всех рабочих функций.

## Работает

- **Чат** — offline база + память + Википедия + опционально LLM
- **Ход мысли + подпись** — шаги и локальный SHA-256
- **Поиск** — Википедия
- **Заметки / файлы** — IndexedDB / localStorage
- **Квант** — учебный Bell / суперпозиция (2 кубита)
- **Счёт / голос / локальный ID**
- **LLM** — Ollama + backend, только если включите
