# АКСИ — продукт (релиз 1.0)

## Одна фраза
**Локальный ИИ в браузере:** спрашиваете → отвечает на устройстве → можете научить фактами → можете зашифровать память. Облако не обязательно.

## Для кого
- Кому важна **приватность**
- Кому нужен **offline-интеллект** без регистрации
- Командам, которые хотят **agent runtime**, а не ещё один SaaS-чат

## Модель продукта (4 действия)

| Действие | Вкладка | Что происходит |
|----------|---------|----------------|
| **Спросить** | Чат | Offline-ядро (Mind L2 + Neuro) |
| **Научить** | Память | Факт → локальная RAG-память |
| **Защитить** | Доверие | AES + файл `.aksi` |
| **Проверить** | Лаб | Оценка ответа (QCLI) + клиентская симуляция |

Опционально: большая LLM (WebGPU), P2P SDP.

## Честно о «кванте»
Клиентский симулятор и метрики целостности ответа. **Не** доступ к физическому QPU.
