AKSI Mandate Protocol

Мандат на решение и действие: без evidence — BLOCK. С подписью — portable receipt. Проверка offline.

product v1.1 ECDSA-P256-SHA256 default-deny no LLM required not AGI
goal → evidence → gate ALLOW|BLOCK → sign receipt → offline verify

Зачем

Агент не должен действовать «потому что модель так сказала». Нужен проверяемый мандат.

Для кого

Internal tools, MCP gate, compliance demo, air-gap — где важен audit trail.

Что не является

Не чатбот. Не foundation model. Не «сознание». Слой доверия к решению.

Крипто

Настоящая ECDSA P-256 в браузере. Подмена JSON ломает verify.
